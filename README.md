# MAD302 Assignment 2 - Product List App
Overview
Android app demonstrating a RecyclerView-based product list with cosmetic items. Users can select a product to view detailed information on a separate screen using Intent data passing. Implements ViewBinding, clean architecture, and basic input validation. Developed for MAD302 Assignment 2.

Features
- Displays product list using RecyclerView  
- Click on item to view details  
- Data passed between activities using Intent  
- ViewBinding for efficient UI handling  
- Basic input validation  

Technologies Used
- Kotlin  
- Android Studio  
- RecyclerView  
- ViewBinding  
- ConstraintLayout  


Project Structure
- `MainActivity` → Displays product list  
- `DetailActivity` → Shows selected product details  
- `Product` → Data class for product model  
- `ProductAdapter` → RecyclerView adapter  

How It Works
1. App loads a list of cosmetic products  
2. User selects a product from RecyclerView  
3. Data is passed via Intent  
4. DetailActivity displays selected product info  

Screens
- Product List Screen  
- Product Detail Screen  

Requirements Fulfilled
- RecyclerView implementation  
- Intent data passing  
- Two XML layouts only  
- Clean UI and navigation
